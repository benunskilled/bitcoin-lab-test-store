Add a Peer

Add & Keep makes a peer manual and locks it, so it keeps its slot even while offline. The lock above undoes that.

Slot Fill

Fills free manual slots where your node has the fewest connections: other regions, other providers.

How it works
  • When a manual slot is free, it goes to a peer from a missing region, taken from Core's address book.
  • Core tests it. If Core can't connect, the next one is tried.
  • A manual peer that is offline for an hour frees its slot. One that ever delivered a block first gets a day.
  • Working peers and Core's own connections are never touched.
