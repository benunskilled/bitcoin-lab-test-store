# Bitcoin Lab Test Store

Pre-release builds of [Bitcoin Lab](https://github.com/benunskilled/bitcoin-lab) and [Peer Map](https://github.com/benunskilled/peer-map), used to test a release on a real Umbrel before it is tagged (fresh install and update, see the release checklist in [bitcoin-lab-community-store](https://github.com/benunskilled/bitcoin-lab-community-store/blob/main/RELEASE-CHECKLIST.md)).

**Not for general use.** Install the released apps from the [Bitcoin Peer Lab store](https://github.com/benunskilled/bitcoin-lab-community-store) instead. The test apps use their own IDs (`bltest-…`) and ports (8794, 8795), so they can run beside the released ones; both read from the same Bitcoin node.
